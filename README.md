# Network-Automation-Labs

A collection of Python network automation labs using Netmiko.

## 📚 Repository Overview

This repository contains hands-on network automation scripts and labs as part of my journey into network engineering and automation.

### Purpose

* Practice real-world network automation tasks
* Document my learning progress with Netmiko
* Build a practical portfolio for junior network / NOC roles

| Lab Name                  | Topics Covered                          | Status      |

| Multi-device Scripting    | Looping through multiple devices        | Planned     |
